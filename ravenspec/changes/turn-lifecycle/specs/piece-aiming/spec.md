## ADDED Requirements

### Requirement: 点选己方棋子

玩家 MUST 能通过点击棋盘内的己方棋子使其进入选中态；选中后棋子必须显示可辨识的高亮，并使 `ACTION` 阶段推进到 `SELECT`。

#### Scenario: 点中己方棋子进入选中态

- **WHEN** 阶段机位于 `ACTION`，玩家点击棋盘内一枚可操作的己方棋子
- **THEN** 该棋子进入选中态并显示高亮，阶段机推进到 `SELECT`

#### Scenario: 点击棋盘外不选中

- **WHEN** 玩家在棋盘矩形之外点击鼠标
- **THEN** 没有任何棋子进入选中态，阶段机停留在 `ACTION`

#### Scenario: 点击非己方棋子不选中

- **WHEN** 玩家点击一枚敌方棋子或不可操作的棋子
- **THEN** 该棋子不进入选中态，阶段机停留在 `ACTION`

### Requirement: 瞄准线仅在选中后显示

瞄准线 MUST 只在存在选中棋子的情况下绘制；未选中任何棋子时，棋盘上不得出现瞄准线。

#### Scenario: 未选中不画线

- **WHEN** 阶段机位于 `ACTION` 且没有任何棋子被选中
- **THEN** 棋盘上不绘制瞄准线，无论鼠标位于何处

#### Scenario: 选中后瞄准线跟随鼠标

- **WHEN** 一枚棋子被选中，玩家在棋盘内移动鼠标
- **THEN** 瞄准线从该棋子指向鼠标当前位置，并随鼠标移动实时更新

#### Scenario: 鼠标移出棋盘保留上次方向

- **WHEN** 一枚棋子被选中，玩家把鼠标移出棋盘矩形
- **THEN** 瞄准线保持指向鼠标离开棋盘前的最后一个盘内位置，不消失也不跳变

### Requirement: 蓄力

在存在选中棋子的前提下按住左键 MUST 使蓄力值按固定速率增长，并以蓄力条的形式可视化；蓄力值必须存在上限，达到上限后不再增长。

#### Scenario: 按住左键蓄力增长

- **WHEN** 阶段机位于 `SELECT` 且已选中一枚棋子，玩家按住左键
- **THEN** 阶段机推进到 `CHARGE`，蓄力值从 0 开始按固定速率增长，蓄力条随蓄力值伸长

#### Scenario: 蓄力达到上限

- **WHEN** 玩家持续按住左键超过蓄满所需时间
- **THEN** 蓄力值停在上限不再增长，蓄力条保持满格，棋子不被发射

#### Scenario: 未选中时按住左键

- **WHEN** 阶段机位于 `ACTION` 且没有任何棋子被选中，玩家按住左键
- **THEN** 不进入 `CHARGE`，蓄力值保持为 0

### Requirement: 激发是不可撤销点

松开左键 MUST 是本次发射唯一的不可撤销点：松开时沿"棋子指向瞄准点"的方向施加与蓄力值成正比的冲量，蓄力值清零并清除瞄准线，阶段机推进到 `MOTION`；此后本回合不得重来。

#### Scenario: 松开左键发射棋子

- **WHEN** 阶段机位于 `CHARGE` 且蓄力值大于 0，玩家松开左键
- **THEN** 棋子沿瞄准方向获得与蓄力值成正比的冲量，蓄力值清零，瞄准线清除，阶段机推进到 `MOTION`

#### Scenario: 零蓄力松开

- **WHEN** 阶段机位于 `CHARGE` 且蓄力值仍为 0，玩家松开左键
- **THEN** 棋子不被施加冲量，但阶段机仍推进到 `MOTION` 并按静止判定结束本阶段

#### Scenario: 发射后不可撤销

- **WHEN** 棋子已被激发并处于 `MOTION` 阶段
- **THEN** 玩家无法通过任何鼠标操作把棋子位置或蓄力值恢复，也无法在本回合重新发射该棋子

### Requirement: 取消选中与改选

在尚未按住左键时，玩家 MUST 能取消当前选中，也 MUST 能改选另一枚己方棋子；取消后阶段机回到 `ACTION`。

#### Scenario: 点空白处取消选中

- **WHEN** 阶段机位于 `SELECT` 且玩家尚未按住左键，玩家点击棋盘内空白处
- **THEN** 选中态被清除，高亮与瞄准线消失，阶段机回到 `ACTION`

#### Scenario: 按 Esc 取消选中

- **WHEN** 阶段机位于 `SELECT` 且玩家尚未按住左键，玩家按下 Esc
- **THEN** 选中态被清除，高亮与瞄准线消失，阶段机回到 `ACTION`

#### Scenario: 改选另一枚棋子

- **WHEN** 阶段机位于 `SELECT` 且玩家点击另一枚可操作的己方棋子
- **THEN** 选中态转移到新点击的棋子，原棋子的高亮消失，阶段机保持在 `SELECT`

### Requirement: 发射机会每回合仅一次且任意本方角色可选

发射前，本方**任意**角色 MUST 可被选中；一次发射发生后，本方所有角色在本回合内 MUST NOT 再被选中，只能被碰撞推动。发射机会 MUST NOT 实现为可累加的"剩余次数"资源。

#### Scenario: 发射前可选中或改选任意本方角色

- **WHEN** 阶段机位于 `ACTION` 或 `SELECT`，且本回合尚未发射
- **THEN** 点击任意一枚本方角色都使其进入选中态；点击另一枚时选中态转移，原角色高亮消失

#### Scenario: 本回合已发射后无法再选

- **WHEN** 本回合已有一枚角色被激发，且阶段机尚未回到 `TURN_START`
- **THEN** 玩家点击任何本方角色均不进入选中态

#### Scenario: 未发射的本方角色仍可被推动

- **WHEN** 一枚本回合未被发射的本方角色被运动中的角色撞击
- **THEN** 该角色按物理规则被推动，其位移不受"每回合仅一次发射"的限制

### Requirement: 结束回合是玩家回合的唯一出口

玩家回合 MUST NOT 自动结束。回合结束 MUST 只能由玩家点击"结束回合"按钮触发；点击后 MUST 清除选中态与瞄准线，并在结算与表现排空后进入 `TURN_END`。整回合不发射 MUST 是合法操作。

#### Scenario: 不发射直接结束回合

- **WHEN** 阶段机位于 `ACTION`，玩家未点选任何角色就点击"结束回合"按钮
- **THEN** 阶段机跳过 `SELECT`、`CHARGE`、`MOTION`、`HIT_SETTLE`、`ZOC_SETTLE` 直接进入 `TURN_END`，且没有任何角色被施加冲量、没有任何角色因此获得补偿或惩罚

#### Scenario: 已选中时点击结束回合

- **WHEN** 阶段机位于 `SELECT` 且已有角色被选中，玩家点击"结束回合"按钮
- **THEN** 选中态与瞄准线被清除，阶段机直接进入 `TURN_END`

#### Scenario: 回合不会自行结束

- **WHEN** 阶段机位于 `ACTION`，玩家既不点选角色也不点击"结束回合"，无论等待多久
- **THEN** 阶段机停留在 `ACTION`，不因任何计时或"已无事可做"的推断而推进

#### Scenario: 表现未播完时点击结束回合

- **WHEN** 玩家点击"结束回合"时仍有表现未播完
- **THEN** 已有表现不被中断，等到结算与表现排空后才进入 `TURN_END`

#### Scenario: 非玩家回合按钮不可用

- **WHEN** 阶段机位于 `ENEMY_TURN` 或其他非玩家操作阶段
- **THEN** "结束回合"按钮不响应点击

### Requirement: 操作许可由阶段机发放

棋子 MUST NOT 自行判断当前是否可被操作；是否响应鼠标输入必须由阶段机按当前阶段与棋子归属统一裁决。

#### Scenario: 非操作阶段棋子静默

- **WHEN** 阶段机处于 `MOTION`、`HIT_SETTLE`、`ZOC_SETTLE`、`TURN_END` 或 `ENEMY_TURN`
- **THEN** 所有棋子均不响应鼠标按下与松开事件

#### Scenario: 同一时刻至多一枚棋子被选中

- **WHEN** 阶段机已有一枚棋子处于选中态
- **THEN** 其他棋子申请进入选中态被拒绝，除非玩家显式改选
