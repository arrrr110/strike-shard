# 术语表

> 状态：编写中
> 目的：全项目统一叫法。文档、spec、代码命名都以此为准。

## 对局与回合

| 术语 | 英文 / 代码名 | 定义 |
| --- | --- | --- |
| 对局 | match | 从开局到分出胜负的完整过程。持有**玩家血量**、回合计数等跨回合持久状态 |
| 回合 | turn | 一方的一次行动周期。玩家回合与敌方回合交替；回合计数在 `ENEMY_TURN` 结束时 +1 |
| 阶段 | phase | 回合内的一个步骤。阶段机在任一时刻只处于一个阶段，用 `UPPER_SNAKE` 命名（`ACTION` / `MOTION` …） |
| 阶段机 | game flow | 驱动阶段序列推进的脊梁。每个物理帧轮询一次当前阶段的完成条件，**至多推进一个阶段** |
| 回合上下文 | `TurnContext` | 只存活一个回合的瞬时状态：行动角色、瞄准点、力度、命中记录、本回合已发射标记 |

## 角色与棋盘

| 术语 | 英文 / 代码名 | 定义 |
| --- | --- | --- |
| 角色 | combatant / `Combatant` | **逻辑实体**：归属方、攻击、血量、控制域半径、卡片序号、挂载技能。是结算的作用对象 |
| 棋子 | piece | **物理实体**：角色在棋盘上的 `RigidBody2D` 表现，负责碰撞、摩擦、贴图倾斜。与角色一一对应 |
| 归属方 | owner | 角色属于哪一方。`0` = 玩家方，`1` = 敌方 |
| 卡片序号 | `card_index` | 角色所对应卡片的序号，由**内容层**提供，核心只把它当作定序键的一个字段 |
| 控制域 | ZOC (zone of control) | 角色周围半径 `zoc_radius` 的圆形范围。**纯查询**得到覆盖关系，不缓存、不存状态 |
| 围攻 | siege | 敌方角色 X 同时被"本回合发射的行动角色"与至少一名其他己方角色覆盖时成立。伤害单向，只伤 X |
| 交换 | exchange | 未成围攻时，覆盖方与被覆盖方之间的**双向**伤害结算 |
| 静止 | rest | 棋盘级判定：全场所有棋子的线速度与角速度分别低于各自阈值，且持续 N 个物理帧 |
| 发射 | launch | 玩家消耗本回合唯一一次发射机会，把一枚本方角色弹出。是不可撤销点 |
| 行动 | action | `ACTION` 枢纽上可做的一件事：出牌、发射、结束回合 |

## 结算与表现

| 术语 | 英文 / 代码名 | 定义 |
| --- | --- | --- |
| 事件 | event / `GameEvent` | 机制里**唯一的真相载体**：发生了什么。纯数据，可序列化，可回放 |
| 结算 | settle / resolve | 事件引起的状态改变（扣血、死亡、局面翻转）。只能改状态，不能画东西 |
| 表现 | presentation | 结算的可视化（伤害数字、爆炸、位移、闪光）。只读事件，**不回查规则** |
| 时间线 | timeline | 一串表现步骤及其具名标记，是表现的时钟 |
| 标记 | marker | 时间线上的具名时间点（`hit` / `end`）。想要在动效某一刻结算的规则订阅标记；不关心的规则在事件产生时立刻结算 |
| 效果规则 | `EffectRule` | "某类事件发生时要做什么"的契约实现。输入一个事件，输出**一组新事件**，绝不直接调用另一条规则 |
| 事件队列 | event queue | 串行排空事件的容器。链式效果靠"处理完一个再入队"展开，**不用递归** |
| 全序键 | order key | 给事件排序用的整数数组，字典序比较。保证任意两个事件都有确定先后 |
| 物理闸门 | `PhysicsGate` | 引用计数的物理冻结开关。唯一持有者是时间线 |
| 冻结 | freeze | 暂停物理积分而**不**暂停场景树：`PhysicsServer2D.set_active(false)` |
| 溢出伤害 | overflow | 超出角色**总血量**的部分，累积并结算到**玩家血量**上 |

## 架构三桶

| 术语 | 定义 | 硬约束 |
| --- | --- | --- |
| 契约 | 只有接口与数据结构，零逻辑 | 核心只依赖契约；契约里不得出现具体角色名/卡名 |
| 工具类 | 纯函数，无状态 | 不缓存、不改状态；同一份数据被结算、UI、AI 复用 |
| 桥 | 把内容接进核心的单向适配层 | 核心不反向依赖内容；只有桥知道"有哪些角色/卡片/技能" |

## 玩家血量 vs 角色血量

- **角色血量**（`hp` / `max_hp`）：单个角色的耐久。归零即该角色倒下。
- **玩家血量**：一方的总耐久池，独立于角色。角色受到的**溢出伤害**累积到这里。
- 两者是不同的状态，不得互相代替；界面上也是两个不同的显示区域。
