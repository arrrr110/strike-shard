# 《弹棋·三国》 MVP 核心设计 v6

> **两个要素，统一参数，动态手牌。**  
> 取消材质系统、统一 ZOC、引入 e 衰减系数。专属卡洗回牌库。疲劳防僵局。

---

## 要素一：棋子走位、碰撞和攻击机制

### 1.1 统一物理——单一参数 e

所有棋子物理属性完全一致。唯一的物理变量是**碰撞衰减系数 e**：

| e 值       | 行为               | 手感        |
| --------- | ---------------- | --------- |
| e = 0     | 完全弹性碰撞，能量无损      | 弹珠台，全场乱弹  |
| 0 < e < 1 | 部分衰减（默认 e = 0.3） | 标准物理，弹几下停 |
| e = 1     | 完全非弹性，碰撞后静止      | 台球精准走位    |

e 同时作用于棋子碰撞和边缘碰撞。默认 e = 0.3，卡牌可临时修改。

| 参数    | 值       | 说明            |
| ----- | ------- | ------------- |
| 质量    | 2.0     | 所有棋子统一        |
| 摩擦    | 0.4     | 所有棋子统一        |
| e（衰减） | 0.3（默认） | 卡牌可修改         |
| 边缘反弹  | 受 e 影响  | e=0 时边缘也是完全弹性 |

### 1.2 统一 ZOC

所有棋子的控制域半径完全相同：

| 参数     | 值               |
| ------ | --------------- |
| ZOC 半径 | **2.0**（所有武将统一） |

差异化完全交给被动技能 + 专属卡。

### 1.3 得分体系

| 场景              | 得分            | 触发时机  |
| --------------- | ------------- | ----- |
| 碰撞敌方棋子          | 3 分           | 碰撞即时  |
| 敌方在 1 个 ZOC 内   | 8 分           | 回合结算  |
| 敌方在 2 个 ZOC 交叠内 | 24 分          | 回合结算  |
| 敌方在 3 个 ZOC 交叠内 | 48 分          | 回合结算  |
| 敌方撞荆棘边缘         | 质量×速度×(1-e)   | 碰撞即时  |
| 敌方飞出棋盘          | 质量×速度×(1-e)×2 | 出界即时  |
| 疲劳伤害            | 递增（见 2.5）     | 抽牌时触发 |

### 1.4 棋盘边缘

棋盘内部完全空旷。四边均为弹性碰撞边缘，衰减率为e：

| 边缘  | 碰撞效果         |
| --- | ------------ |
| 弹性边 | 按当前 e 反弹，不扣分 |
|     |              |
|     |              |

### 1.5 碰撞的定位

碰撞是走位工具，不是独立玩法：

| 用途   | 说明              |
| ---- | --------------- |
| 位移敌方 | 撞进己方 ZOC 或撞向荆棘边 |
| 位移己方 | 队友当弹板，撞到更好位置    |
| 打断走位 | 破坏敌方 ZOC 覆盖阵型   |

## 要素二：卡片构筑、手牌和势机制

### 2.1 势

| 项目 | 说明                                |
| -- | --------------------------------- |
| 范围 | 0 ~ 10                            |
| 获取 | 回合结算时，每有 1 个敌方棋子处于己方 ZOC 内 → +1 势 |
| 用途 | 支付卡牌费用                            |
| 规则 | **所有卡牌都需要费用，没有 0 费卡**             |

### 2.2 牌库结构

| 牌区              | 内容        | 说明                              |
| --------------- | --------- | ------------------------------- |
| **牌库（Deck）**    | 基础卡 + 专属卡 | 抽牌来源                            |
| **手牌（Hand）**    | 从牌库抽取     | 上限 10 张，初始 3 张，后手玩家多1张，另外多一张势卡。 |
| **坟场（Discard）** | 使用过的基础卡   | 不再可用（除非有特殊卡）                    |
| **专属卡回流**       | 使用后的专属卡   | **洗回牌库**，可再次抽到                  |

**关键设计**：

- 基础卡是一次性的（用完进坟场）
- 专属卡是可循环的（用完洗回牌库）
- 专属卡的随机回流创造"什么时候能再抽到"的期待感

### 2.3 卡牌规则

| 规则   | 说明                      |
| ---- | ----------------------- |
| 费用   | 所有卡牌消耗势，无 0 费卡          |
| 多张使用 | 每回合可消耗多张卡牌              |
| 基础卡  | 可作用于任意棋子（含敌方），通常是全局物理修改 |
| 专属卡  | 只能作用于该武将自身的棋子           |

### 2.4 基础卡牌池

> 修改物理参数，全局生效，进坟场。

| 卡名    | 费用 | 效果                      |
| ----- | -- | ----------------------- |
| 完全弹性  | 3  | 本回合 e = 0（全场弹珠台，碰撞能量无损） |
| 绝对静止  | 3  | 本回合 e = 1（碰了就停，精准走位）    |
| 衰减减半  | 2  | 本回合 e × 0.5（更弹，滑更远）     |
| 衰减加倍  | 2  | 本回合 e × 2，上限 1（更粘，停更快）  |
| 大力出奇迹 | 3  | 本回合击打力度双倍（初速度双倍）        |
| 精准    | 2  | 棋子预览路径无视首个碰撞点，延申到第三个碰撞点 |
| 延域    | 2  | 本回合所有 ZOC 半径 +0.5       |
| 额外射击  | 4  | 本回合可额外击打 1 枚棋子          |
| 穿透    | 3  | 本回合棋子穿过第一个碰撞目标          |
|       |    |                         |

### 2.5 疲劳机制

| 条件        | 效果                                  |
| --------- | ----------------------------------- |
| 牌库为空时需要抽牌 | 受到疲劳伤害                              |
| 疲劳伤害      | 第 1 次 1 分，第 2 次 2 分，第 3 次 3 分……逐次递增 |
| 疲劳伤害目标    | 自己的 HP                              |

**设计意图**：防止僵局。棋子不死的游戏最怕"谁都打不死谁"。疲劳把时钟交给牌库——牌越打越少，压力越来越大，逼双方加快节奏。

**注意**：专属卡洗回牌库会延缓疲劳，但不能完全避免（基础卡是有限的）。

### 2.6 武将设计（被动 + 专属卡）

被动不再常驻，而是**触发式**：被攻击时、攻击时、或与专属卡联动时激活。

#### MVP 三个武将

| 武将     | 被动                       | 触发条件 | 专属卡 | 费用 | 专属效果                                             |
| ------ | ------------------------ | ---- | --- | -- | ------------------------------------------------ |
| **关羽** | 温酒：ZOC范围内只有1名敌方随从时，加3攻击力 | 攻击触发 | 拖刀计 | 5  | 本回合ZOC内有两名或以上敌方随从时，首先攻击最近的敌方随从，然后攻击最远的敌方随从且攻击力翻倍 |
| **赵云** | 白马银枪：每次撞击敌方随从后，速度不衰减     | 碰撞触发 | 龙胆  | 4  | 本回合每撞击过一次，增加一点攻击力                                |
| **周瑜** | 抚琴：身边有友方随从时，ZOC面积扩大一倍    | 攻击触发 | 业火  | 4  | ZOC 内燃火，对所有敌方随从造成伤害                              |

**被动触发类型**：

- **攻击触发**：你的棋子碰撞敌方时激活
- **碰撞触发：**
- **被攻击触发**：
- **常驻**：
- **专属联动**：打出专属卡时附带激活（后续武将设计）

## 三、回合生命周期

```
┌─────────── 玩家操作阶段 ───────────┐
│                                    │
│  1. 卡牌部署（可多张，可与步骤2交替） │
│     - 打卡 → 预览路径实时更新        │
│     - 再打卡 → 再看预览              │
│                                    │
│  2. 瞄准 + 蓄力                    │
│     - 拖拽设定方向和力度            │
│     - 预览路径显示到首次碰撞前       │
│     - 可反复调整，可回到步骤1补卡    │
│                                    │
│  3. 确认结束回合                    │
│                                    │
└────────────────────────────────────┘
          ↓ 确认后不可撤销
┌─────────── 自动结算阶段 ───────────┐
│                                    │
│  4. 卡牌激活 + 棋子射入             │
│     - 播放运动动画                  │
│     - 首次碰撞后的连锁不可预测       │
│                                    │
│  5. 全局静止 → 攻击结算 + 计分      │
│     - 碰撞基础分                    │
│     - ZOC 覆盖分                    │
│     - 边缘惩罚分                    │
│                                    │
│  6. 计分扣入对方血条                │
│                                    │
│  7. 抽牌 1 张（若牌库空 → 疲劳）    │
│                                    │
└────────────────────────────────────┘
          ↓ 切换
       对方回合
```

**关键设计**：

- 步骤 1-3 可交替操作，非严格顺序
- 预览路径只到首次碰撞 → 首次碰撞前完全可控
- 碰撞后连锁 = 不可预测 = 兴奋点（你选择碰撞就是选择赌博）
- 不碰撞纯走位 = 完全可预测 = 稳健策略

## 四、减少毒点 / 增加兴奋点

### 4.1 毒点清单与对策

| 毒点           | 原因      | 对策                         |
| ------------ | ------- | -------------------------- |
| 瞄准了但碰撞结果不可预测 | 物理复杂    | 预览到首次碰撞 + 统一物理 + e 透明      |
| 被对方包夹无法反抗    | 被锁死     | 每回合必能射 1 枚 + 碰撞可破坏阵型       |
| 抽不到好牌        | 随机性     | 专属卡洗回（可循环）+ 基础卡都有用         |
| 被一波 combo 秒杀 | 爆发过高    | combo 需多回合攒势 + 对方能看到 setup |
| 无限僵局         | 棋子不死    | 疲劳机制强制收束                   |
| 专属卡被系统锁住     | v5 的势门禁 | 取消门禁，专属卡在牌库里               |

### 4.2 兴奋点清单

| 兴奋点       | 触发方式                    |
| --------- | ----------------------- |
| ZOC 交叠大分  | 2-3 枚棋子走位到位，24-48 分入账   |
| 连锁碰撞      | 一击触发多体碰撞，意外把敌方弹进 ZOC    |
| e=0 弹珠台   | 打出完全弹性卡，全场弹飞，混乱中得高分     |
| 专属卡 combo | 抽到专属卡 + 势够 + 局面到位，一回合终结 |
| 破坏对方阵型    | 一击打散对方的 2 域交叠           |
| 疲劳极限翻盘    | 双方低血，最后一抽翻盘             |
