# 《弹棋·三国》 Roguelike 关卡策划 v7

> **三幕式关卡、奖励卡牌池、神器系统、三阶段最终Boss。**  
> 基于 v6 核心规则：统一物理 e 系数、统一 ZOC、专属卡洗牌库、疲劳机制。

---

## 一、关卡结构总览

### 1.1 三幕结构

```
Act 1: 虎牢关前路  (8 层 → Boss 华雄)
     ↓ 胜利 → 选择一件神器（精良品质）
Act 2: 洛阳之争    (9 层 → Boss 董卓)
     ↓ 胜利 → 选择一件神器（稀有品质）
Act 3: 虎牢关决战  (8 层 → 最终 Boss 吕布)
     ↓ 胜利 → 通关！
```

### 1.2 节点类型

| 节点     | 图标  | 内容                            | 奖励              |
| ------ | --- | ----------------------------- | --------------- |
| 普通战斗   | ⚔️  | 标准敌人                          | 3 选 1 卡牌 + 少量金币 |
| 精英战斗   | 💀  | 更强敌人，更好奖励                     | 3 选 1 卡牌 + 大量金币 |
| 商店     | 🛒  | 消耗金币购买卡牌 / 神器                 | —               |
| 休息     | 🔥  | 恢复 30% HP，或升级 1 张卡            | —               |
| 事件     | ❓  | 随机事件：正面/负面/二选一                | 不定              |
| Boss   | 👹  | 小Boss / 最终Boss                | 神器 + 卡牌         |

### 1.3 地图生成规则

每个 Act 是 3-4 列的多行分支地图。玩家从底部向上推进，每行选择 1 个节点进入，无法走回头路。

```
Act 1 示例布局（从下往上推进）:

             [华雄👹]          ← 第 8 层
            /       \
      [普通⚔️]    [商店🛒]      ← 第 7 层
       /    \     /    \
   [事件❓] [精英💀] [事件❓]      ← 第 6 层
     |       |       |
   [普通⚔️] [普通⚔️] [普通⚔️]      ← 第 5 层
     |       |       |
   [休息🔥] [普通⚔️] [商店🛒]      ← 第 4 层
     |       |       |
   [普通⚔️] [精英💀] [事件❓]      ← 第 3 层
     |       |       |
   [普通⚔️] [普通⚔️] [普通⚔️]      ← 第 2 层
     |       |       |
   [普通⚔️] [普通⚔️] [普通⚔️]      ← 第 1 层
         起点（必须全通过）
```

> **设计原则**：至少保证每条路径都有一次休息节点。精英节点和商店节点交错分布，鼓励玩家做路线选择。

## 二、敌方设计

### 2.1 基础属性统一

| 参数           | 玩家棋子 | 敌方棋子 |
| ------------ | ---- | ---- |
| 基础攻击力        | 4    | 4    |
| 质量           | 2.0  | 2.0  |
| 摩擦           | 0.4  | 0.4  |
| e（衰减）        | 0.3  | 0.3  |
| ZOC 半径       | 2.0  | 2.0  |
| 每回合可射击棋子数    | 1    | 1    |

> **关键设计**：所有棋子基础攻击力相同（4），敌方没有数值优势——他们的优势是**数量多**。

### 2.2 敌方 AI 行为树

```
敌方回合：
  1. 手牌检查 → 有卡可打且势够 → 随机打 0-2 张
  2. 射击决策（优先级从高到低）：
     a. 若能碰撞玩家棋子 → 瞄准碰撞（最高优先级）
     b. 若能走位到 ZOC 覆盖玩家棋子 → 瞄准走位
     c. 若己方棋子被玩家 ZOC 覆盖 → 瞄准碰撞救出
     d. 否则 → 向玩家半场随机射击
  3. 结算 → 同玩家回合生命周期
```

AI 的意图是**可读的**——玩家能看到 AI 的射击方向预览线（同玩家的预览机制），可以预判 AI 的策略并提前走位应对。

### 2.3 敌方团队属性

| 战斗类型 | 敌方棋子数 | 敌方 HP | 基础卡牌数 |
| ---- | ----- | ----- | ----- |
| 普通战斗  | 4-5   | 60-80 | 0-2   |
| 精英战斗  | 5-6   | 80-100| 2-4   |
| 小Boss | 5-6   | 100-120| 3-5  |
| 最终Boss| 4-6(分阶段)| 150(50×3)| 5-8 |

### 2.4 敌方棋子类型（外观差异，数值全统一）

| 类型    | 外观特征         | AI 偏好        | 出现幕数   |
| ----- | ------------ | ------------ | ------ |
| 步卒    | 基础士兵，圆形灰甲    | 普通 AI        | Act 1-3 |
| 弓手    | 外圈有箭头标识      | 偏好远距离走位      | Act 1-3 |
| 骑兵    | 稍大轮廓，有速度线    | 偏好高速碰撞       | Act 2-3 |
| 谋士    | 内圈有八卦纹路      | 偏好打牌辅助其他棋子   | Act 2-3 |
| 陷阵营   | 赤色重甲，略大面积    | 偏好包夹 ZOC 覆盖  | Act 3  |

> 类型差异仅体现在 AI 行为偏好和外观，物理属性完全一致。

### 2.5 敌方血量阶梯

| Act | 普通敌人 HP | 精英敌人 HP |
| --- | -------- | -------- |
| 1   | 60       | 80       |
| 2   | 70       | 90       |
| 3   | 80       | 100      |

## 四、小 Boss 设计

### 4.1 Act 1 Boss：华雄

> **主题**：蛮力碾压，教玩家基本的防守走位。

| 属性       | 值          |
| -------- | ---------- |
| 敌方棋子数    | 5          |
| 敌方 HP   | 100        |
| 牌库       | 3 张基础卡     |
| 特殊场地     | 无          |
| 战斗开场     | 敌方棋子在中线一字排开 |

**阶段机制**：

| 阶段   | 触发条件     | 效果                         |
| ---- | -------- | -------------------------- |
| 第一阶段 | 开局       | 标准战斗                       |
| 第二阶段 | HP < 40% | 触发「狂暴」：本回合 e=0，华雄击打力度 +50% |

**AI 强化**：第二阶段华雄偏好高速碰撞玩家棋子，试图制造连锁碰撞。

**华雄掉落**：3 选 1 **精良神器**（见第六章）+ 50 金。

---

### 4.2 Act 2 Boss：董卓

> **主题**：叠加多重机制。场地障碍 + 阶段强化，教玩家管理多个维度的威胁。

| 属性       | 值          |
| -------- | ---------- |
| 敌方棋子数    | 6          |
| 敌方 HP   | 120        |
| 牌库       | 5 张（含 1 张紫卡） |
| 特殊场地     | 棋盘上有 2 个酒坛 |

**酒坛机制**：

- 酒坛：质量 1.0 的障碍物，被碰撞后碎裂。
- 碎裂时对周围（半径 1.5）所有棋子造成 5 点伤害（不分敌我）。
- 每 3 回合随机位置生成 1 个新酒坛，场上最多 3 个。

**阶段机制**：

| 阶段   | 触发条件     | 效果                                |
| ---- | -------- | --------------------------------- |
| 第一阶段 | 开局       | 酒坛机制激活                            |
| 第二阶段 | HP < 50% | 触发「暴虐」：所有己方棋子攻击力 +2（持续整场），董卓打出「全军突击」 |

**策略要点**：玩家可以利用酒坛——把敌方棋子撞向酒坛，酒坛碎裂伤害敌方。但酒坛也是障碍物会挡住己方走位。

**董卓掉落**：3 选 1 **稀有神器**（见第六章）+ 3 选 1 紫卡 + 60 金。

## 六、最终 Boss：吕布

> **三阶段战斗**。每阶段改变场地和机制，类似《杀戮尖塔》铜人/觉醒者。

### 6.1 总览

| 属性      | 值               |
| ------- | --------------- |
| 总 HP    | 150（50 × 3 阶段）  |
| 棋子数     | 4 → 5 → 6      |
| 牌库      | 6 张基础卡 + 2 张稀有卡 |
| 第一/二阶段间 | 自动切换，HP 条满格刷新    |
| 第二/三阶段间 | 自动切换，HP 条满格刷新    |

### 6.2 第一阶段：飞将（HP 0-50）

| 项目     | 内容                            |
| ------ | ----------------------------- |
| 敌方棋子数  | 4                             |
| 场地     | 标准棋盘                           |
| 敌方被动   | 飞将：每次碰撞后，吕布获得 1 势              |
| 行为模式   | 频繁碰撞玩家棋子攒势，偶尔走位制造 ZOC 覆盖       |
| 策略提示   | 优先避免被碰撞——吕布攒势快，不控制的话会频繁打出高费卡  |
| 转阶段效果  | "奉先，热身结束。" — 棋盘边缘变为荆棘边（碰边扣分） |

### 6.3 第二阶段：辕门射戟（HP 0-50）

| 项目     | 内容                            |
| ------ | ----------------------------- |
| 敌方棋子数  | 5                             |
| 场地     | 四边均为荆棘边                       |
| 新增被动   | 飞将（保留）+ 射戟：每 3 回合，吕布射击 1 枚额外棋子 |
| 卡牌      | 获得「穿透」卡（3 费，本回合棋子穿过第一个碰撞目标）  |
| 行为模式   | 在荆棘边的威胁下逼迫玩家走位，再用穿透卡破坏玩家阵型   |
| 策略提示   | 远离边缘走位，优先用卡牌控速避免被推入荆棘边        |
| 转阶段效果  | "吕布怒了！" — 清除所有荆棘边，e 永久设为 0（弹珠台模式）+ 吕布随从 +1 |

### 6.4 第三阶段：天下无双（HP 0-50）

| 项目     | 内容                                    |
| ------ | ------------------------------------- |
| 敌方棋子数  | 6                                     |
| 场地     | e=0 全场弹珠台，"棋盘中央生成面积 10% 的深渊区域"（棋子落入即扣 15 分并被弹回） |
| 新增被动   | 无双：吕布每次碰撞玩家棋子时，额外获得 1 势（总共 +2/碰撞）      |
| 专属卡     | 打出「天下无双」（8 费）：选择 1 枚己方棋子，攻击力 ×3，质量 ×2，击飞全场 |
| 行为模式   | 弹珠台混沌中疯狂攒势，攒够打出「天下无双」终结比赛            |
| 策略提示   | 在弹珠台中反而要控制走位——远离深渊，避免被无双棋子击飞           |

**胜利**：击败第三阶段 → 通关结算 → 展示本局数据统计。

## 九、难度曲线与数值基准

### 9.1 玩家资源变化

|      | Act 1 开局 | Act 1 结束 | Act 2 结束 | Act 3 结束 |
| ---- | -------- | -------- | -------- | -------- |
| HP   | 100      | 60-100   | 50-100*  | 0-100*   |
| 牌库数  | 13       | 16-20    | 20-26    | 24-32    |
| 神器数  | 0        | 1        | 2        | 2        |
| 金币   | 0        | 80-120   | 100-180  | 80-150   |

> *取决于休息节点使用情况。

### 9.2 单回合理论伤害对比

| 场景        | 期望伤害（保守）           | 期望伤害（combo）               |
| --------- | ------------------ | ------------------------- |
| Act 1 开局  | 3（碰撞）+ 8（1 ZOC）= 11 | 3 + 24（2 ZOC）= 27          |
| Act 1 Boss | 7（攻击+3）+ 24 = 31   | 7 + 48（3 ZOC）= 55          |
| Act 2      | 11 + 24 = 35       | 乾坤一掷：所有碰撞 ×2 → 70+         |
| Act 3      | 15 + 48 = 63       | 背水一战：攻击力 ×3 → 150+（理论一回合终结） |

> 设计目标：普通回合 10-30 伤害，combo 回合 40-80，极限 combo 100+。Act 3 中 6-7 回合可击败普通敌人（HP 80-100）。

### 9.3 疲劳时钟

| 回合数（牌库耗尽后） | 疲劳伤害        |
| ---------- | ----------- |
| 第 1 次抽牌    | 1           |
| 第 2 次      | 2           |
| 第 3 次      | 3           |
| 第 n 次      | n           |

以 Act 1 普通战（敌方 HP 60）为例：即使运气极差打不出 ZOC，纯靠碰撞（每回合约 3-5 点），15-20 回合也能结束战斗——但此时疲劳伤害已经累积到 10+/回合，实际上 12-15 回合必然结束。**疲劳防止无限僵局，但不会在正常对局中成为主要伤害来源。**
